# AI Code Reviewer & Repository Auditor

An intelligent, full-stack code review and repository auditing platform that analyzes source code for quality, security, performance, and architecture using AI and RAG (Retrieval-Augmented Generation).

---

## Architecture & Tech Stack

- **Frontend:** React, Next.js, Tailwind CSS, Monaco Editor
- **Backend:** Node.js, Express.js
- **Database:** MongoDB with Mongoose
- **Authentication:** JWT (JSON Web Tokens)
- **File Uploads:** Multer
- **AI Engine:** Google Gemini / OpenAI
- **Vector Database:** Pinecone
- **RAG Framework:** LangChain.js
